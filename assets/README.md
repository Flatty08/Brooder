# Required Assets

Please add the following image files to this folder:

1. **icon.png** - App icon (1024x1024 recommended)
2. **splash-icon.png** - Splash screen image
3. **adaptive-icon.png** - Android adaptive icon (foreground)
4. **favicon.png** - Web favicon

## Temporary Workaround

Until you add these images, the app references to these files have been commented out in:

- `app.json` (icon references)
- `screens/SignupScreen.js` (logo require)
