# Internet of Tsiken v2 🐔

IoT-based brooder management system for monitoring and controlling chicken brooder environments.

## Features

- 📊 **Real-time Monitoring**: Temperature, humidity, water level, feed level, solar charge, and lighting
- 📈 **Reports**: Generate and view batch reports with statistics
- 📝 **Activity Logs**: Track all system activities with date/time filtering
- ⚙️ **Smart Controls**: Automated environmental control
- 🌞 **Solar-Powered**: Energy-efficient with solar integration
- 📱 **Mobile-First**: Built with React Native and Expo

## Tech Stack

- **Framework**: React Native (Expo)
- **Navigation**: React Navigation
- **Icons**: React Native Vector Icons
- **State Management**: React Hooks
- **Storage**: AsyncStorage

## Installation

```bash
# Clone repository
git clone https://github.com/YOUR_USERNAME/Internet-of-Tsiken-v2.git

# Navigate to directory
cd Internet-of-Tsiken-v2

# Install dependencies
npm install

# Start development server
npx expo start
```

## Usage

1. Scan QR code with Expo Go app (iOS/Android)
2. Or run on emulator/simulator
3. Navigate through Home, Control, Analytics, Reports, and Activity Logs
