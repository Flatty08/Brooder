# Required Assets

Please add the following image files to the `./assets/` folder:

1. `icon.png` - App icon (1024x1024 recommended)
2. `splash-icon.png` - Splash screen image
3. `adaptive-icon.png` - Android adaptive icon (foreground)
4. `favicon.png` - Web favicon

Temporary workaround: You can use any PNG images with these names, or remove the references from app.json if not needed yet.
